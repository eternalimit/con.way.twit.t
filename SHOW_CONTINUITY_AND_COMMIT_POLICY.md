## Episode archival rule

For every subsequent episode:

1. Find the complete finished episode script and verify its identity, episode number and continuity; do not substitute a synopsis for a complete script.
2. Check the exact target path on the current repository branch before writing; use an immutable, versioned episode path; do not overwrite other episodes or protected originals.
3. Commit the episode to `eternalimit/con.way.twit.t` only if publication of that particular episode's content is authorized. The repository is **public**, so committing here immediately makes text publicly accessible.
4. Fetch back the saved file and compare its complete contents to the version committed. Report the actual Git commit SHA, file blob SHA and any limits or blockers.
5. Do not claim a poster image is saved unless its real binary file was separately added and verified.

## Locked final scene / presentation order

1. Cinematic rocket-launch finale and blackout.
2. Rocket-themed cinematic episode-ending poster, actually generated when available and authorized; otherwise label the poster as an unrendered concept.
3. Rocket stub with the next episode title and teaser.
4. Functional NEXT / CONTINUE control in interactive conversation, where supported, or a copyable continuation prompt.

## Publication boundary

**0 HOLD** stays in force for protected MASTER.ORIGIN assets, third-party art/music/likenesses, private family material, and any other content without specific release authorization. Do not interpret this document as permission to copy all old transcripts or publish protected source artifacts. Do not change repository visibility or deploy websites merely because a commit is authorized.
